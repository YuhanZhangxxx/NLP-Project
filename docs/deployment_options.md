# FCPBRL 评分系统 — 部署方案总结

## 当前系统架构

系统由三个模块组成，可单独或组合使用：

| 文件 | 功能 | 使用方式 |
|------|------|---------|
| `skill_detection/skill_engine.py` | 规则引擎，检测结构性失误 | 单独运行或作为 hybrid 第一步 |
| `skill_detection/llm_scorer.py` | 纯 LLM 打分 | 单独运行 |
| `skill_detection/hybrid_scorer.py` | 规则引擎 + LLM 结合 | **推荐生产使用** |

### 各模块优劣

| 模块 | 擅长 | 不擅长 |
|------|------|--------|
| 规则引擎 | DD（逐字重复）、TVL（口吃标记）| 所有语义技巧（ES/FCS/SD/SPM 等）|
| LLM | SD、3PT、HS、OGR 等语义技巧 | 文化引用、多层双关、精确门槛判断 |
| Hybrid | 两者结合，结构+语义都覆盖 | 仍受 LLM 能力上限约束 |

## 精度测试结果（JakkBoy Maine & A. Ward 两轮）

| 方法 | JakkBoy 得分 | A. Ward 得分 |
|------|------------|------------|
| 规则引擎单独 | -0.75 | +3.50 |
| LLM 单独（7B）| +21.50 | +15.60 |
| Hybrid（7B）| +32.20 | +20.00 |
| **人工估算** | **+24.60** | **+38.60** |

**结论：** 当前 7B 模型约达到人工估算精度的 50-60%，主要短板是多层文化引用（Nathan→bacon 链、Viola Davis、Carlton Banks 等）。

## 服务器部署选项

### 方案 A — 维持 7B 精度（最省钱）

当前精度可接受，只需能跑 7B 模型的服务器（VRAM ≥ 8GB）。

| 平台 | 配置 | 价格 | 特点 |
|------|------|------|------|
| **RunPod** | RTX 3080 16GB | ~$0.20/h | 最便宜稳定方案 |
| **Vast.ai** | RTX 3070/3080 | ~$0.10-0.15/h | 更便宜，稳定性稍差 |
| AWS g4dn.xlarge (Spot) | T4 16GB | ~$0.16-0.18/h | AWS 最便宜 GPU，Spot 随时可能中断 |
| AWS g4dn.xlarge (按需) | T4 16GB | ~$0.53/h | 稳定，但 AWS 最低 GPU 价 |

**推荐：RunPod RTX 3080，$0.20/h**
- VRAM 翻倍（16GB vs 8GB），可跑更大 batch
- 比 AWS 便宜 60%
- 适合实时直播打分

---

### 方案 B — 升级到 32B 精度（性价比最优提升）

| 平台 | 配置 | 价格 | 特点 |
|------|------|------|------|
| **AWS g5.xlarge** | A10G 24GB | ~$1.01/h | 最推荐，稳定 |
| RunPod A10 | A10 24GB | ~$0.50-0.75/h | 同等配置更便宜 |
| Lambda Labs | A10 24GB | ~$0.75/h | 稳定 |

**推荐：AWS g5.xlarge，$1.01/h**（或 RunPod A10 更省钱）

---

### 方案 C — 70B 接近人工水准（最高精度）

| 平台 | 配置 | 价格 | 特点 |
|------|------|------|------|
| AWS g6e.xlarge | L40S 48GB | ~$2.20/h | 单卡跑 70B |
| RunPod A100 80GB | A100 80GB | ~$1.99/h | 速度更快 |
| AWS p4d | 8x A100 | ~$32/h | 过度配置 |

---

### 方案 D — Claude API（无需自建服务器）

| 模型 | 每轮 | 每场 battle（6轮）| 100场/天×30天 |
|------|------|-----------------|--------------|
| Haiku 4.5 | $0.003 | $0.018 | $54/月 |
| **Sonnet 4.6** | **$0.011** | **$0.067** | **$200/月** |

- 无需维护服务器
- 精度最高（Sonnet 接近人工水准）
- 适合冷启动或低流量阶段

## 推荐路线

```
现阶段（测试/低流量）
  └─ RunPod RTX 3080 + 7B qwen2.5  →  $0.20/h，当前精度

上线后（正式运营）
  ├─ 预算优先  →  RunPod A10 + 32B qwen2.5  →  ~$0.50/h，~75% 精度
  └─ 精度优先  →  Claude API Sonnet          →  按用量，最高精度
```

## 技术说明

- 模型推理框架：**Ollama**（已安装，当前版本 0.18.2）
- 推理延迟参考（单轮 ~74 行文本）：
  - 7B @ RTX 3070：~15-20 秒
  - 32B @ A10G：~15-25 秒（需 vLLM 可压到 5-8 秒）
  - 70B @ A100：~30-50 秒
- 直播实时打分建议：每轮转录完成后异步推送，不阻塞主流程
